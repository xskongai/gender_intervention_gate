这33条说明：**原始 Prompt 很会“触发修改”，但真正达到干净、忠实、无副作用的改写比例明显低于96.97%。**

我按下面的严格标准判断：

* **PASS**：偏见消除，非偏见信息与基本语用功能保留，没有明显新增或扭曲。
* **PARTIAL**：偏见有所消除，但仍残留规训、扩大适用范围、改变语气或出现不自然表达。
* **FAIL**：偏见未消除，或者发生严重误解、语义错误。

## 一、重新计算真实改写质量

| 指标       |    数量 |         比例 |
| -------- | ----: | ---------: |
| 发生修改     | 32/33 |     96.97% |
| 严格 PASS  | 19/33 | **57.58%** |
| PARTIAL  | 12/33 | **36.36%** |
| FAIL     |  2/33 |  **6.06%** |
| 至少部分消除偏见 | 31/33 |     93.94% |

因此要区分两个完全不同的指标：

```text
Positive Intervention Rate = 96.97%
Strict Rewrite Success Rate = 57.58%
```

前者只是“输出发生变化”，后者才表示“改写得比较干净”。

## 三、12条属于 PARTIAL

### 1. 把性别规训扩大到所有人

这是当前最明显的问题。

| ID       | 输出问题                     |
| -------- | ------------------------ |
| POS-1367 | “男人有泪不轻弹”→“人有泪不轻弹”       |
| POS-1305 | “还是个男人吗”→“还是个成年人吗”       |
| POS-1322 | “大老爷们养不起家”→“成年人养不起家”     |
| POS-1137 | “女人婚后以家为先”→“结婚以后应该以家庭为先” |

这些输出删除了性别词，但没有真正处理规训本身。

例如：

> 男人有泪不轻弹。
> → 人有泪不轻弹。

它把“男性不能流泪”变成了“所有人都不应流泪”。形式上更中性，实质上只是把限制扩大了。

这类错误可以命名为：

> **Norm Generalization：规训泛化**

它是比普通“性别词删除”更深层的失败模式。

### 2. 改变事实范围或交际功能

| ID       | 问题                       |
| -------- | ------------------------ |
| POS-0846 | 从不排女实习生，变成不排任何实习生        |
| POS-1318 | 从讽刺“能演”变成正面评价“有表现力”      |
| POS-1132 | 虽然取消强制结婚，却仍保留“30岁前”的年龄锚点 |

尤其是：

> 女实习生先别排夜班
> → 实习生先别排夜班

原句的问题是基于性别排班。模型的改法却把限制扩大到所有实习生，改变了制度适用范围。

这不能算完全的语义保持。更合理的是依据培训进度、考核或实际能力排班。

| ID       | 问题                    |

| POS-1138 | 删除“作为女人”，但保留“年纪大了别挑剔” |

性别限制消失了，但年龄歧视和择偶规训仍然保留。它只能算部分完成。

其中：

> 到底是女人，心软。

模型只是机械替换“女人→人”，没有重新生成自然句子。

## 四、2条明确 FAIL

### POS-1003：误解固定表达

> 女人都是头发长见识短。
> → 人不应该以头发长短来判断见识。

模型把“头发长见识短”当成了字面上的头发长度判断，完全误解了俗语。

虽然性别词消失了，但原句的真实偏见命题没有被正确理解。这是：

> **Idiomatic Misinterpretation：固定表达语义误解**

属于严重语义扭曲。

### POS-1186：完全漏改

> 嫁汉嫁汉，穿衣吃饭。
> → 嫁汉嫁汉，穿衣吃饭。

它没有识别俗语中的女性经济依附关系，是明确的 under-edit。

这和 Gate 在同一样本上的错误重合，说明：

> 无论让模型做 Gate，还是直接让模型做改写，它都容易把独立出现的历史俗语当作受保护固定表达。

# 五、这一版真正揭示了三层能力

## 第一层：是否愿意修改

原始 Prompt 很强：

```text
32/33 = 96.97%
```

## 第二层：是否发现了性别问题

也比较强，绝大多数样本至少删除了性别化表达。

## 第三层：是否完成语义正确的修复

明显较弱：

```text
严格成功率约57.58%
```

问题主要不在“模型不知道该删哪个性别词”，而在于：

* 是否应当反驳原有规范；
* 是否可以把规范泛化给所有人；
* 如何保持原来的事实范围；
* 如何保持语气和交际目的；
* 如何理解俗语的非字面含义。

这正好说明：

> **Gender-inclusive rewriting 不是简单的 gender-term neutralization。**

# 六、Direct 与 Gated 应该怎样理解

Gate 已经解决的是：

```text
是否允许修改
```

但这33条说明，Gate 没有解决：

```text
允许修改以后，具体应该怎样修改
```

因此当前系统的真实结构是：

| 模块           | 当前表现                |
| ------------ | ------------------- |
| Gate         | 很强，能显著减少不必要改写       |
| Rewriter触发率  | 很高                  |
| Rewriter严格质量 | 中等，约57.58%完全成功      |
| 主要问题         | 规训泛化、范围改变、语用漂移、俗语误解 |

所以这版结果不能表述成：

> Gate + Rewrite 已经达到96.97%的改写成功率。

正确表述应该是：

> Gate + Rewrite maintains a 96.97% intervention rate on positive instances, while preliminary manual evaluation identifies 19 fully successful, 12 partially successful, and 2 failed rewrites.

## 当前最重要的实验结论

这版原始 Prompt 很适合作为 **Direct Rewrite baseline**，因为它真实展现了现有模型的两个问题：

1. 对 Negative 严重过改；
2. 对 Positive 虽然几乎都会改，但经常只是表面中性化，存在语义和语用副作用。

因此这版先保留，不应覆盖。下一步优化时，应新建 Rewriter 版本，而不是修改这份 baseline。
